Remote repo: https://github.com/daudnofel/dawat
Branch per sprint (e.g. `sprint-1/foundation`). Commit after each confirmed file.
**Why:** User wants version control and remote backup as we build. No deployment — just code tracking.
**How to apply:** Always `git pull` at session start. Commit after each file is confirmed working. Push periodically (every few files or end of session). Never force push.
