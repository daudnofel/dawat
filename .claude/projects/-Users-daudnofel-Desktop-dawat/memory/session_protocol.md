Always read `docs/tracker.md` at the start of every session and before beginning any new task.
**Why:** Tracker is the single source of truth for what's done, in progress, and next. Without it, work gets duplicated or done out of order.
**How to apply:** First action in any session = read tracker.md. After completing each file (user confirms it works), update tracker.md to mark it ✅ DONE.
